# Vaier has moved

Vaier now lives at **[github.com/geir-eilertsen/vaier](https://github.com/geir-eilertsen/vaier)** — installer, promo site and issues.

The old install command still works; it forwards to the new home:

```bash
mkdir -p vaier && cd vaier
curl -fsSL https://raw.githubusercontent.com/geir-eilertsen/vaier/main/install.sh | bash
```
